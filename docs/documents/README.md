# Project Documents

This folder stores the public artifacts for the senior project website.

## Expected milestone filenames

Use lowercase filenames with hyphens and no spaces. Recommended names include:

- `project-plan.pdf`
- `requirements.pdf`
- `design.pdf`
- `testing.pdf`
- `presentation.pdf`
- `progress-evaluation.pdf`
- `poster.pdf`
- `user-manual.pdf`
- `developer-manual.pdf`
- `demo-video.mp4`

## Folder layout

Place files according to the semester and milestone structure used by the website:

- `documents/first-semester/project-plan/`
- `documents/first-semester/milestone-1/`
- `documents/first-semester/milestone-2/`
- `documents/first-semester/milestone-3/`
- `documents/second-semester/project-plan/`
- `documents/second-semester/milestone-4/`
- `documents/second-semester/milestone-5/`
- `documents/second-semester/milestone-6/`

## .gitkeep files

The `.gitkeep` files are placeholders for empty folders. Remove them when real documents are added to the folder.
