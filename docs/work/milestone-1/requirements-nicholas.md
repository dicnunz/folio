# Folio Requirement Document — Nicholas Half

## Functional Requirements

- **F1.** The system shall allow the student to select an assignment, test, or other coursework to address.
- **F2.** The system shall allow the student to choose a planning template.
- **F3.** The system shall allow the student to edit suggested tasks.
- **F4.** The system shall allow the student to accept an instructor suggestion.
- **F5.** The system shall allow the student to reject an instructor suggestion.
- **F6.** The system shall allow the student to adapt an instructor suggestion before applying it to the plan.
- **F7.** The system shall allow the student to decide whether to revise the plan after instructor feedback.
- **F8.** The system shall provide a daily view of scheduled tasks.
- **F9.** The system shall provide a weekly view of scheduled tasks.
- **F10.** The system shall allow the student to reschedule a task.
- **F11.** The system shall allow the student to configure reminders.
- **F12.** The system shall allow the student to mark a task complete.
- **F13.** The system shall show a progress bar for each plan.
- **F14.** The system shall provide a congratulatory response when the student completes a task.
- **F15.** The system shall allow the student to use the planning workflow without instructor participation.
- **F16.** The system shall allow the student to use the planning workflow without the game or rewards.
- **F17.** The system shall use course information as planning context without inferring studying, attendance, participation, or effort outside the system.

## Interface Requirements

- **I1.** The system shall export a plan as a PDF.
- **I2.** The system shall export a plan as a DOCX.
- **I3.** The system shall prepare an instructor email and present it to the student for review before sending.
- **I4.** The system shall allow the student to choose which academic plan information is prepared for instructor sharing.
- **I5.** The system shall exclude progress, reward, and game information from academic exports and prepared instructor emails.

## Performance Requirements

- **P1.** The system shall preserve the student’s entered and edited plan information when the plan is saved or revised.
- **P2.** PDF, DOCX, and prepared email outputs shall accurately contain the academic plan information selected for sharing.
- **P3.** The displayed task-completion and plan-progress information shall match the student’s saved task-completion status.
